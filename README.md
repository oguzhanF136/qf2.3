# QuantiFlows

Kripto piyasalarını analiz etmek için gelişmiş teknik analiz araçları ve gerçek zamanlı veri akışı sağlayan bir platform.

## Özellikler

- Gerçek zamanlı kripto verileri
- Teknik analiz göstergeleri
- Long/Short oranları analizi
- Karanlık/Aydınlık tema desteği
- Responsive tasarım

## Kurulum

1. Projeyi klonlayın:
```bash
git clone https://github.com/yourusername/quantiflows.git
cd quantiflows
```

2. Bağımlılıkları yükleyin:
```bash
npm install
```

3. Geliştirme sunucusunu başlatın:
```bash
npm run dev
```

4. Production sunucusunu başlatın:
```bash
npm start
```

## Kullanılan Teknolojiler

- Node.js
- Express.js
- HTML5
- CSS3
- JavaScript

## Güvenlik

Proje aşağıdaki güvenlik önlemlerini içerir:
- Helmet.js ile güvenlik başlıkları
- CORS koruması
- Rate limiting
- Input validasyonu
